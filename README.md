# Wonny Calculator

맥북 책상 위에 놓고 싶은, 입체적인 키와 따뜻한 색감의 작은 계산기. Tauri 2 + Svelte 5로 개발합니다.

Claude Code 기반으로 개발해 온 개발자가 **Codex의 기능과 개발 과정을 벤치마크**하기 위한 공개 프로젝트입니다. 작은 기능을 테스트부터 작성하고 구현하며, 화면 시안을 검토한 뒤 다음 단계로 진행합니다. 이 저장소는 제품 개발 실험이며, 정량적인 모델 성능 측정 결과를 주장하지 않습니다.

## 첫 번째 단계 · v0.1

- 아이보리 본체, LCD 느낌의 표시창, 주황색 키의 CSS 입체 UI
- 기본 사칙연산, 소수점, 부호, 백분율, 초기화, 한 자리 지우기
- 계산기 본체만 채우는 작은 네이티브 창, 기울기와 웹페이지 소개 영역 제거
- 상단 닫기·최소화·일반/큰 크기 전환, 상단을 잡아 창 이동
- 둥근 외곽과 투명 창 배경, 스크롤 없는 고정 높이 레이아웃
- 아날로그 스위치 형태의 Ivory / Sage / Midnight 색상 선택, 선택값 로컬 저장
- 최근 계산 5개를 내부 상태에 보관 (기록 UI는 현재 숨김)
- 숫자 키, `+`, `-`, `*`, `/`, `Enter`, `Escape`, `Backspace` 지원
- 일반 계산기처럼 입력 순서대로 연산: `2 + 3 × 4 = 20`
- 12자리 입력 제한, 유한한 결과는 유효숫자 12자리로 표시, 0으로 나눌 때 오류 복구

현재 이미지 생성 도구가 연결되지 않아 생성형 이미지 에셋은 포함하지 않습니다. 화면은 CSS로 구현했고 네이티브 개발용 아이콘은 코드로 만든 임시 아이콘입니다. 생성 에셋을 도입할 때 프롬프트와 출처를 함께 기록합니다.

## 개발

Node.js 22.12 이상, npm, Rust stable, Xcode Command Line Tools가 필요합니다.

```sh
npm install
npm test
npm run check
npm run dev
```

브라우저: `http://127.0.0.1:1420`

```sh
npm run tauri dev
npm run tauri build
```

네이티브 빌드는 macOS의 `.app`과 `.dmg`를 대상으로 합니다. 현재 Apple 서명과 공증은 설정하지 않았습니다.
둥근 투명 창 구현을 위해 Tauri의 `macos-private-api` 기능을 사용합니다. 현재 배포 대상은 GitHub 직접 배포이며 Mac App Store 심사는 검증하지 않았습니다.

```sh
npm run preview:export
```

`previews/first-edition.html`은 서버 없이 브라우저에서 열 수 있는 현재 UI 시안입니다. 소스를 수정하면 위 명령으로 다시 생성합니다.

## 개발 방식

1. 작은 기능의 입력과 예상 결과를 테스트로 정의합니다.
2. 테스트 실패를 확인하고 최소 구현으로 통과시킵니다.
3. 타입 검사와 프로덕션 빌드를 확인합니다.
4. 시안을 검토한 뒤 다음 기능을 선택합니다.

계산 로직은 Svelte에서 분리한 순수 상태 전이로 테스트합니다. 버튼과 키보드는 같은 로직을 사용합니다. UI 클릭과 네이티브 창 동작은 별도 실행 검증이 필요합니다.

첫 단계 검증과 환경 제약은 [개발 기록](DEVELOPMENT.md)에 기록합니다.
